# CSS Selectors Practice

A frontend practice project demonstrating core CSS selection techniques, pseudo-classes, and structural pseudo-elements without relying on inline styling or extra IDs.

## Features

- Class and ID selectors targeting specific heading elements.
- Element styling for standard paragraph and heading tags.
- Structural pseudo-classes (`:first-of-type`, `:last-of-type`) to style anchor tags without adding classes or IDs.
- Child pseudo-classes (`:nth-child()`) to apply distinct colors to individual ordered list items.

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
├── index.html
└── style.css

```

## Getting Started

1. Clone or download the repository.
2. Open `index.html` directly in your browser, or launch it using a local development server such as VS Code Live Server.
